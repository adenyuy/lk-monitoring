LKLK Monitoring

Kebijakan Privasi

Berlaku untuk aplikasi LK Monitoring, aplikasi internal Tim Monitoring Revitalisasi SD 2026. Terakhir diperbarui 27 Oktober 2026.

Izin Google yang diminta

  • Alamat email akun Google: untuk mencocokkan pengguna dengan daftar akses tim.
  • Google Sheets: untuk membaca sheet Broadcast, LK, dan Akses milik tim, serta menulis isian LK dan penanda warna pengiriman ke sheet tim tersebut. Aplikasi tidak membuka spreadsheet lain.

Di mana data disimpan

Aplikasi berjalan di laptop pengguna. Token login Google, riwayat pengiriman, log aktivitas, dan sesi WhatsApp disimpan di laptop itu saja (folder %APPDATA%\LKMonitoring). Tidak ada server milik aplikasi yang menerima data tersebut. Isian LK disimpan di Google Sheets tim.

Berbagi data

Data tidak dijual dan tidak dibagikan ke pihak ketiga. Pesan WhatsApp dikirim dari akun WhatsApp pengguna sendiri melalui WhatsApp Web, hanya ke nomor fasilitator yang tercantum di sheet tim.

Penggunaan data Google

Penggunaan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus data

Pengguna dapat keluar dari aplikasi (menu profil, lalu Keluar), mencabut izin di myaccount.google.com/permissions, dan menghapus folder %APPDATA%\LKMonitoring di laptopnya.

Kontak

Hubungi admin Tim Monitoring melalui GitHub Issues.
